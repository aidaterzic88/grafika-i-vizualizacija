# Grafika i Vizualizacija

Kolekcija praktičnih radova i grafičkih rješenja rađenih u okviru predmeta **Grafika i vizualizacija**.

## Sadržaj repozitorija
- **Dizajn brendinga:** Izrada logotipa, vizitkarte i pečata.
- **2D/3D modeliranje:** Dizajn i renderovanje razglednice te 2D/3D modela.

##  Alati i tehnologije
- **Inkscape** – Vektorska grafika (logo, vizitkarta, pečat)
- **GIMP** – Rastarska grafika i obrada slika (razglednica)
- **SketchUp** – 3D modeliranje i dizajn
